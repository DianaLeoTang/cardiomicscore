# 文章核心信息提取

AI-based multiomics profiling reveals complementary omics contributions to personalized prediction of cardiovascular disease

DOI:https://doi.org/10.1038/s41467-026-68956-6

## 研究方法

### 1. 研究设计
- **数据来源**: UK Biobank队列研究
- **样本分层策略**: 两阶段个体水平数据划分
  - Metabolomics-only cohort (N=220,859)
  - Proteomics-only cohort (N=19,086)
  - Multiomics cohort (N=24,287) - 作为独立验证集
- **地理验证**: 将England/Wales作为训练/验证集，Scotland作为地理测试集

### 2. 核心算法架构

**CardiOmicScore框架**包含两个多任务深度学习模型:

#### MetNet (代谢组学模型)
```
输入: 168个代谢物
架构: 
- Shared MLP (共享网络层)
- 6个疾病特异性MLP分支
- 每个分支输出一个疾病的MetScore
损失函数: 加权二元交叉熵
  - 样本级加权: pos_weight = 阴性样本数/阳性样本数
  - 任务级加权: weight = 1/阳性样本数
```

#### ProNet (蛋白质组学模型)
```
输入: 2,920个蛋白质
架构: 与MetNet相同
输出: 每个疾病的ProScore
```

### 3. 模型训练细节

**超参数优化**:
- 使用Optuna进行随机搜索
- 100个随机配置
- 优化目标: 验证集上6种CVD的平均C-index

**模型集成**:
- 使用最优超参数训练5次(不同随机种子)
- 最终预测分数为5次运行的平均值

### 4. 下游分析

**Cox比例风险模型**:
```
预测变量组合:
- 临床变量集: AgeSex, Clin, PANEL
- 组学特征: PRS, MetScore, ProScore
- 组合模型: PANEL + PRS/MetScore/ProScore
```

## 核心数据

### 1. 组学数据规模
- **代谢组学**: 168个代谢物 (NMR平台)
  - 脂蛋白亚类、脂肪酸、氨基酸、糖酵解代谢物等
- **蛋白质组学**: 2,920个蛋白质 (Olink Explore平台)
  - 覆盖心血管代谢、炎症、神经、肿瘤4个panel
- **基因组学**: 疾病特异性PRS
  - CAD: 235 SNPs
  - Stroke: 63 SNPs
  - HF: 38 SNPs
  - AF: 154 SNPs
  - PAD: 19 SNPs
  - VTE: 297 SNPs

### 2. 临床变量集定义

**AgeSex**: 年龄 + 性别

**Clin** (25个变量):
- 人口学信息
- 生活方式因素
- 家族史
- 疾病/用药史
- 体格测量

**PANEL** = Clin + 血液学指标(9个)

## 主要结果

### 1. 预测性能 (C-index in Multiomics cohort)

**单一组学特征**:
```
ProScore: 0.69-0.82 (VTE到PAD)
MetScore: 0.64-0.74
PRS: 0.52-0.60
```

**组合模型增益** (相比PANEL基线):
```
PANEL + ProScore: ΔC-index = 0.023-0.049
PANEL + MetScore: ΔC-index = 0.012-0.027
PANEL + PRS: ΔC-index = 0.003-0.019
PANEL + All omics: 最大增益
```

### 2. 关键生物标志物

**代谢物** (跨疾病共享):
- 肌酐、白蛋白、谷氨酰胺
- 脂肪酸: LA, MUFA
- 脂蛋白: IDL_FC, XL_HDL_FC, XXL_VLDL_CE
- 炎症标志物: GlycA

**蛋白质**:

*共享标志物*:
- GDF15 (CAD, HF, AF, VTE)
- NT-proBNP, NPPB (CAD, HF, AF)
- MMP12 (CAD, PAD)

*疾病特异性*:
- Stroke: KLK4, CRIP2
- AF: BCAN, ELN  
- PAD: PLB1, ENDOU
- VTE: HPGDS, ADGRG2

### 3. 临床效用

**风险分层能力**:
- MetScore和ProScore的高、中、低三分位组间生存曲线显著分离 (log-rank P < 0.001)

**校准度**:
- PANEL基线模型校准良好
- 加入组学特征后校准度进一步提升

**净获益**:
- A-NBC改善幅度: 35.39 (stroke) 至 212.36 (AF)

### 4. 模型稳健性

**地理验证**: MetScore和ProScore在Scotland测试集表现稳定

**亚组分析一致性**:
- 年龄、性别分层
- 降脂/降压药物使用状态分层
- 排除2年内早期病例
- 竞争风险分析(死亡作为竞争事件)

## 设计亮点

1. **多任务学习架构**: 同时预测6种CVD，捕获疾病间共享和特异性特征

2. **两阶段验证策略**: 
   - 地理验证(Scotland)
   - 独立队列验证(Multiomics)

3. **模型可解释性**: 使用SHAP识别重要生物标志物

4. **实用性考量**: 提供在线演示平台用于风险评分计算

## 局限性

1. 代谢组学panel以脂质相关标志物为主，可能遗漏其他代谢途径
2. 基线单时间点测量，未捕获动态变化
3. UK Biobank主要为欧洲裔白人，需多种族验证
4. 缺乏独立外部队列验证
